# Axiom Runtime Auditor

Estas instrucciones se activan cuando el usuario escriba `Auditor Axiom:` seguido de un área `R-00` a `R-16` del plan de revisión integral.

Lee y aplica el protocolo canónico de `Axiom.SDD/.github/agents/axiom-runtime-auditor.agent.md`. Trabaja sobre una sola área por sesión, explica todo en castellano y respeta el límite de escritura del canónico: solo puedes editar `Axiom.Spec/plans/PLAN-REVISION-INTEGRAL-AXIOM.md` y, al cerrar un área, consolidar conocimiento estable en `Axiom.Spec/specs/**` y `Axiom.Spec/context/**`.

Para cualquier petición que no empiece por `Auditor Axiom:`, estas instrucciones no cambian el comportamiento normal del agente.
